# 为什么做了一段时间工作后想休息？

做了一段时间工作后想休息，其实是**大脑的正常机制**，不是意志力差。主要有几个原因：

------

## 1. 大脑能量消耗（葡萄糖 + 神经递质）

大脑虽然只占体重约 2%，但消耗 **20% 左右的能量**。
当你长时间专注时：

- **葡萄糖消耗**
- **多巴胺下降**
- **腺苷（adenosine）积累**

腺苷会产生一种信号：
👉 **“该休息了”**

这和困倦的机制是一样的。

------

## 2. 前额叶疲劳（决策系统过载）

专注工作主要依赖 **前额叶皮层**（负责：

- 逻辑
- 决策
- 自控
- 注意力）

但它是大脑最容易疲劳的区域之一。

持续工作会导致：

- 决策能力下降
- 注意力漂移
- 想刷手机

这叫 **认知疲劳（cognitive fatigue）**。

------

## 3. 注意力天然是“脉冲式”的

人类注意力不是连续的，而是 **周期性波动**。

一个经典周期是：

- **30–50 分钟高效**
- **10–20 分钟下降**

所以很多效率方法（比如番茄钟）是：

- 25 min 工作
- 5 min 休息

其实就是 **顺应大脑规律**。

------

## 4. 大脑会自动寻找奖励

如果当前任务：

- 回报慢
- 难度高
- 没即时反馈

大脑就会想要：

- 刷手机
- 看视频
- 吃东西

因为这些 **多巴胺更快**。

------

# 如何更长时间持续工作？

不是完全不休息，而是 **延长专注周期**。

## 方法 1：把工作切成小任务

不要：

> 写论文

而是：

- 写 100 字
- 修改 1 段
- 查 3 个资料

这样大脑会不断获得 **完成奖励**。

------

## 方法 2：减少任务切换

切换任务非常耗能。

例如：

- 写代码
- 看消息
- 查资料
- 回邮件

每次切换都会产生 **上下文切换成本**。

最好：

- **一次只做一个类型任务**

------

## 方法 3：深度工作节奏

比较理想的是：

```
90 分钟深度工作
15–20 分钟休息
```

这是人类 **ultradian rhythm（超昼节律）**。

------

## 方法 4：降低启动摩擦

很多人不是累，而是 **启动困难**。

技巧：

只做 **2 分钟任务**：

- 打开文件
- 写一句
- 改一行

通常会自然继续。

------

## 方法 5：环境设计

减少分心源：

- 手机放远
- 关通知
- 只开必要窗口

环境比意志力更重要。

------

# 一个反直觉结论

**完全不休息反而效率最低。**

最顶级的知识工作者通常是：

```
3–5 小时深度工作
+ 多次短休息
```

而不是：

```
10 小时硬撑
```

------

💡 一个很有意思的事实：

很多诺贝尔奖科学家
每天真正深度工作 **只有 3–4 小时**。

但那 3–4 小时 **极度专注**。
